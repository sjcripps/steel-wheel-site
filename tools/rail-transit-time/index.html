How this works. Class I railroads file average train speed by service type and average terminal dwell with the STB every week under EP 724. We route your lane across the North American rail network, apply each carrier's current speed for the way your traffic actually moves, and add dwell for origin, destination, and each interchange. Unit and shuttle trains bypass classification, so they carry fewer dwell events than a single manifest car. The seasonal comparison uses the same week in prior years, because rail service is strongly seasonal — comparing against a trailing average would report winter as a service failure.
